# Hatim Sampalwala — Portfolio

A horizontal scrollytelling personal portfolio. Vertical scroll drives a camera
along a descending "staircase" of panels, gliding through rounded corners.

**Sections:** Hero · About · Experience (8 roles) · OneStop App project ·
Skills · Tools · Education · Contact.

## Run locally

```bash
python -m http.server 4173
# then open http://localhost:4173
```

It's static — `index.html` plus `css/style.css` and `js/main.js`, no build step.

## Stack

Vanilla HTML / CSS / JavaScript. Fonts: Playfair Display, Libre Franklin,
Oswald, Caveat. Original SVG artwork; no external dependencies.
